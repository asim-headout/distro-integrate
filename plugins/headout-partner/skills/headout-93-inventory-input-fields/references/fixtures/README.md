Every fixture referenced here is re-verifiable: run `node tools/sandbox-scenario-catalog/cli.js verify`
to re-check it against live sandbox, or `... generate-checklist` for the full current status of every
cataloged scenario (`tools/sandbox-scenario-catalog/output/CHECKLIST.md`).

Some scenarios are marked **confirmed absent from sandbox** rather than "not yet found" — these were
searched for across ~120 sandbox cities and thousands of products with zero matches. Implement per the
documented contract regardless; do not skip handling a case just because sandbox can't currently
exercise it, and flag it to the partner as untestable pending Headout sandbox data.
